# Emmanuel Angelo-Hyuwa · Personal Site

**Software engineer in the making · Physics & math at heart**

</div>

My corner of the internet, hand-built with **zero frameworks and zero dependencies**: six pages of semantic HTML, modern CSS and one shared vanilla JavaScript file. Strictly black and white, with film grain, glass surfaces and a live n-body gravity simulation on the home hero, written from scratch in canvas.

## Running locally

There is no build step. Open `index.html` directly, or serve it:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Deploying

Works out of the box on GitHub Pages, Vercel, Netlify or any static host. Just point it at the repo root.
